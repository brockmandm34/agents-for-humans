# Agents for Humans - Project Delivery Agent

An AI-powered project delivery agent built with AWS Strands Agents and Amazon Bedrock.

## Problem

Project managers spend significant time reviewing task lists, identifying overdue work, tracing dependencies, finding blockers, and deciding what needs attention first.

## Solution

This agent helps project managers quickly identify:

- Overdue work
- Project risks
- Blockers
- Dependencies
- Tasks requiring human attention

The agent recommends next actions while keeping important decisions and approvals with the human user.

## Built With

- AWS Strands Agents
- Amazon Bedrock
- Anthropic Claude
- Python
